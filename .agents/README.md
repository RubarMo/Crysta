# Neubrutalism UI for AI Coding Assistants

Canonical, high-contrast, tactile Neubrutalism UI design system and rules for Google Antigravity & AI coding assistants.

## Features

- **0px Border Radius**: Strict physical geometric aesthetic.
- **Heavy Ink Outlines**: 3px / 2px / 4px solid borders.
- **Unblurred Offset Shadows**: Tactile hard shadows with 0 blur.
- **High-Contrast Typography**: Syne (Display), Space Grotesk (Headings), Inter (Body), Space Mono (Code/Numbers), and Dubai/Cairo/Amiri for Arabic BiDi.
- **Neutral Dark Mode**: `#1E1E22` canvas with tactile light shadows.
- **Anti-AI-Slop & Direct Copywriting**: No robotic subtitles, no lonely floating icon boxes, no static marketing pills.
- **Reactive BiDi / RTL**: Global direction synchronization.
